# Solutions — ⚠️ divulgâche intégral

## Antichambre

1. **La natte** au sol → `E`. Elle glisse à droite ; une clé de bronze
   flotte à gauche. Visez-la, `E`.
2. **Le coffret de cèdre**, sur la table à gauche → `E`. Donne le papyrus.
3. **Les quatre nombres** :

   | Formule | Objet | Chiffre |
   |---|---|---|
   | ce qui **brûle** | trépied à trois flammes | **3** |
   | ce qui **saigne** | 16 scarabées, dont 7 de cornaline rouge | **7** |
   | ce qui **sonne** | cadran : gnomon doré sur la 5ᵉ encoche | **5** |
   | ce qui **veille** | deux Anubis devant la dalle | **2** |

   **Code : `3752`**
4. **La stèle** (mur ouest) → `E` : elle découvre la niche.
   **La niche** → `E` → tapez `3752` → `Entrée`. Donne la clé et l'amulette.
5. **Les vases canopes** (mur du fond) : `I·A II·N III·K IV·H`.
6. **La dalle** → `E` → tapez `ANKH` → `Entrée`.

## Les trois sceaux

- **Nord — les Éclats.** Marchez dans la salle : les fragments ralentissent
  et s'allument près de l'unique point de vue où ils forment un ankh.
- **Ouest — les Deux Ombres.** `E` sur le solide, puis glissez : chaque
  glissement le tourne d'un quart de tour. Une orientation sur 24 satisfait
  les deux silhouettes gravées.
- **Est — le Passage.** Murs invisibles, révélés une seconde au contact. Le
  chemin contourne par les bords, jamais par le centre.

## Sortie

Trois sceaux → le couvercle du sarcophage coulisse au centre de la grande
salle. Marchez dedans.
